# AI 新闻日报

每日自动聚合 AITNT、Hacker News、GitHub Trending、arXiv，生成静态日报。

- 在线：https://ruofeng-song.github.io/ai-news-daily/
- 目录：https://ruofeng-song.github.io/ai-news-daily/news/

## 结构

- `news/YYYY-MM-DD/index.html` — 每日日报
- `news/index.html` — 目录（自动生成）
- `sitemap.xml` — 自动生成

内容由 `~/dev/projects/my-site/scripts/daily-ai-news.py` 每日自动生成并推送。
